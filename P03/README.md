# P03: Repositori personal

## Breu descripció

### Introducció

L’ús de **GitHub** i el control de versions mitjançant Git ja és una tècnica que hauríeu d’haver interioritzat. Per tant, no us ha d’estranyar que el repositori de GitHub sigui la base del lliurament del projecte.

A la tasca inicial del projecte, vau crear el vostre repositori a partir del repositori base proporcionat. Ara toca comprovar que el teniu tot llest per al lliurament final.

**Recordatori important:**  
Cada projecte i producte ha de tenir la seva pròpia carpeta seguint el criteri de nomenclatura: `T01`, `T02`, `P01`, `P02`, `P03`, etc.

Dins de cada carpeta ha d’haver-hi:
- Un arxiu **`README.md`** (exactament amb aquest nom) on posareu una descripció de l’activitat (podeu utilitzar l’enunciat resumit).  
  És important que el format sigui **Markdown** i que l’estructureu en seccions clares.
- Un arxiu **`solucio.md`** amb la solució, codi o enllaços necessaris.
- Una carpeta per a les imatges (recomanat: `imatges/`).

## Què cal lliurar

- **Repositori assignat al GitHub Classroom**

> **Important:** No s’accepten lliuraments en repositoris diferents del que us ha estat assignat a GitHub Classroom.
