# Solució: Desplegament de la Web Corporativa

Aquest apartat detalla la solució tècnica implementada per a la publicació de la proposta web de **FoodLogístics**, assegurant que el projecte sigui accessible per als responsables de l'empresa.

## 🛠️ Passos realitzats per a la implementació

Per donar compliment als requisits del projecte, s'han seguit els següents passos tècnics:

1.  **Preparació del Repositori:**
    * S'ha creat i clonat el repositori oficial `web_projecte7`.
    * S'ha configurat l'entorn local per gestionar el control de versions mitjançant Git.

2.  **Estructuració del Projecte:**
    * **Carpeta `/docs`:** S'ha creat aquesta carpeta a l'arrel del projecte per allotjar els fitxers finals de la web (HTML, CSS i JS). Aquesta estructura permet una millor organització i facilita el desplegament.
    * **Documentació:** S'ha completat el fitxer `README.md` amb la informació del projecte, autors i instruccions bàsiques.

3.  **Configuració del Desplegament (Deployment):**
    * S'han pujat els canvis al servidor remot de GitHub (*push*).
    * S'ha activat el servei **GitHub Pages** a l'apartat de *Settings* del repositori, seleccionant la branca `main` i la carpeta `/docs` com a font de publicació.

## 🚀 Resultat Final

La proposta web és ara completament funcional i es pot visitar mitjançant l'URL generada per GitHub Pages. Això permet que el client (**FoodLogístics**) pugui revisar la interfície i el contingut en un entorn real de navegació [Enllaç web](https://classessmx2n.github.io/web-projecte7-RUI0042-DEV/index.html).
