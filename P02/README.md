# P02: Web corporativa

## Breu descripció
Desplegament de la proposta de lloc web per a **FoodLogístics** mitjançant GitHub Pages.

---

## Introducció
A la tasca 8 vau triar quina seria la proposta de pàgina web que presentareu davant els responsables de **FoodLogístics** per substituir la seva pàgina actual. Toca, doncs, desplegar aquesta solució per tal que sigui visible pel client.

---

## Descripció de l’activitat

Per completar la tasca, seguiu aquests punts:

*   **Creació del repositori:** Utilitzeu l'enllaç de la tasca `web_projecte7` que trobareu al Moodle de *Projecte Intermodular*.
*   **Gestió local:** 
    1. Cloneu el repositori a la vostra màquina.
    2. Completeu el fitxer `README.md` amb la informació pertinent.
    3. Creeu una carpeta anomenada `/docs`.
*   **Preparació del codi:** Copieu el codi de la vostra pàgina web dins de la carpeta `/docs`.
*   **Publicació:** 
    1. Pugeu els canvis a GitHub (*commit* i *push*).
    2. Configureu el desplegament a **GitHub Pages** apuntant a la carpeta `/docs`.

> IMPORTANT
> Cal que **tots els membres de l’equip** facin aquesta acció als seus respectius repositoris.
